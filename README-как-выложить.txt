KIRILL WEB — готовая папка сайта

Эта папка содержит уже собранную статическую версию сайта.

Как выложить:
1. Загрузите содержимое этой папки в корневую папку сайта на хостинге.
2. Главный файл сайта — index.html.
3. Не удаляйте папки assets и api, а также файлы manus-routes.json и kirill-web-mark.svg.
4. Если хостинг спрашивает тип сайта, выбирайте статический сайт без PHP и базы данных.

Сайт не требует Node.js, базы данных или сервера: достаточно загрузить содержимое папки на статический хостинг.
