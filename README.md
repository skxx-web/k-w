# Kirill Web

Публичная статическая версия сайта Kirill Web, собранная из предоставленного архива. На странице есть ссылки на Telegram, MAX, электронную почту и пример проекта «Телецбург».

## Публикация

Workflow для GitHub Pages добавлен и публикует файлы при push в ветку `main`, когда Pages включён для репозитория с источником `GitHub Actions`. Публикация ожидает включения Pages в Settings → Pages. Папка `assets` и файл `api/platform/config.js` сохранены; пути в HTML настроены для адреса репозитория `/kirill-web/`. Файл `404.html` сохраняет загрузку интерфейса при прямом переходе на страницу.

Архив содержит собранные HTML/CSS/JavaScript-файлы, а не исходный проект и не серверную часть. В текущей версии формы с отправкой данных на backend нет: контакты открывают внешние мессенджеры или почтовое приложение.
